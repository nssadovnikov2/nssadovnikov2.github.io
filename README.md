# nssadovnikov2.github.io

Сайт-визитка: портфолио и полное резюме. Чистый HTML/CSS без сборки — GitHub Pages
публикует ветку `main` как есть.

- `index.html` — весь текст: проекты, опыт, навыки, контакты
- `styles.css` — оформление, светлая/тёмная тема, версия для печати
- `script.js` — переключатель темы, фильтр портфолио, сохранение в PDF

Локально: `python3 -m http.server 4310` и открыть http://localhost:4310.
Кнопка ⬇ в шапке печатает резюме со всеми раскрытыми деталями — «Сохранить как PDF».
